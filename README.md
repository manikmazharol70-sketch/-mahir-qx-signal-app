# MaHiR QX AI - Quotex Helper

## Chrome installation
1. Extract this ZIP.
2. Open Chrome and go to `chrome://extensions`.
3. Turn on **Developer mode**.
4. Choose **Load unpacked**.
5. Select the folder **MaHiR QX AI - Quotex Helper**.

## GitHub
Upload the contents of the extracted folder to your GitHub repository and commit the changes.

## Important
This build is a visual/helper extension. Automatic trade submission has been disabled, so signals require manual confirmation.
